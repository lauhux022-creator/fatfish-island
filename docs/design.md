# 渔场数值与设计

M1 的玩法数值在 [shared/sim/config.ts](../shared/sim/config.ts) 集中调整。物理固定为 60 Hz，渔获序列使用关卡种子。

## 渔获

| 种类 | 基础售价 | 出现权重 | 收线点击 | 拍晕击数 | 体型系数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 银条鱼 | ¥20 | 52 | 6 | 1 | 0.82 |
| 气鼓鱼 | ¥34 | 32 | 7 | 2 | 1.04 |
| 欠薪斑 | ¥52 | 16 | 8 | 3 | 1.27 |

售价为基础售价乘当前倍率，四舍五入到整数。落入秤盘的有效区域且具有最后触碰者时才入账。大鱼双人抬、炸飞、接鱼和队友当饵等倍率玩法留到后续里程碑。

## 抛钩与场地

| 参数 | M1 数值 |
| --- | ---: |
| 蓄满所需时间 | 1.12 秒 |
| 抛投距离 | 2.8–12.4 米，随蓄力增加 |
| 钩入海到咬钩 | 0.75–1.47 秒 |
| 咬钩后松脱倒计时 | 5.5 秒，收线连点刷新 |
| 木箱收线点击 | 5 次 |
| 玩家基础移速 | 5.25 米／秒 |
| 冲撞训练箱摔倒阈值 | 4 米／秒 |

鱼钩本身参与 Rapier 模拟。落海后，鱼游向钩并咬住；木箱可以在抛投路径上被勾住。弹跳中的鱼带有实体碰撞和角速度，逃回海里即失去本次渔获。
