# 渔场数值与设计

玩法数值在 [shared/sim/config.ts](../shared/sim/config.ts) 集中调整。物理固定为 60 Hz，渔获序列使用关卡种子。

## 渔获

| 种类 | 基础售价 | 出现权重 | 收线点击 | 拍晕击数 | 体型系数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 银条鱼 | ¥20 | 52 | 6 | 1 | 0.82 |
| 气鼓鱼 | ¥34 | 32 | 7 | 2 | 1.04 |
| 欠薪斑 | ¥52 | 16 | 8 | 3 | 1.27 |

售价为基础售价乘当前倍率，四舍五入到整数。落入秤盘的有效区域且具有最后触碰者时才入账。队友饵改变鱼种权重。截胡不会清空已挣到的倍率。大鱼双人抬和炸飞等倍率玩法安排在后续里程碑。

## 抛钩与场地

| 参数 | 数值 |
| --- | ---: |
| 蓄满所需时间 | 1.12 秒 |
| 抛投距离 | 2.8–12.4 米，随蓄力增加 |
| 钩入海到咬钩 | 0.75–1.47 秒 |
| 咬钩后松脱倒计时 | 5.5 秒，收线连点刷新 |
| 木箱收线点击 | 5 次 |
| 玩家基础移速 | 5.25 米／秒 |
| 冲撞训练箱摔倒阈值 | 4 米／秒 |

鱼钩本身参与 Rapier 模拟。落海后，鱼游向钩并咬住；木箱可以在抛投路径上被勾住。弹跳中的鱼带有实体碰撞和角速度，逃回海里即失去本次渔获。

## M2 同班互动

| 条件 | 数值或规则 |
| --- | --- |
| 船员 | 1 位玩家和 3 位机器人 |
| 鱼钩捕获队友半径 | 0.8 米 |
| 被钩队友挣脱时间 | 6 秒 |
| 队友饵落海到咬钩 | 约 0.76 秒 |
| 队友饵鱼种权重 | 银条鱼 0、气鼓鱼 58、欠薪斑 42 |
| 抢鱼范围与新抬鱼保护 | 2.35 米、0.42 秒。半空抛物可直接截胡 |
| 船桨友伤 | 4.4 米／秒水平击飞，布娃娃 2 秒。没有生命扣减 |
| 白班时长 | 240 秒 |
| 结算顺序 | 渔获款降序、卖出尾数降序、入班顺序 |
| 第 1 名奖金 | ¥20 |
| 末位「待优化」 | 次日移速 ×0.90 |
| 自动结算榜展示 | 8 秒 |

团队三名机器人各走各的钓位，使用与玩家相同的蓄力、收线、挥桨、搬运和抛投入参。队友饵本人触碰该鱼时保留上一位有效触碰者。排名取当日渔获款，累计入账额包含奖金。
