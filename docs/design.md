# 渔场数值与设计

玩法数值在 [shared/sim/config.ts](../shared/sim/config.ts) 集中调整。物理固定为 60 Hz，渔获序列使用关卡种子。

鱼钩本身参与 Rapier 模拟。落海后，鱼游向钩并咬住；木箱可以在抛投路径上被勾住。弹跳中的鱼带有实体碰撞和角速度，挥桨可把它横拍出去。鱼离岸后停止反弹，在 0.8 秒内移除并触发逃跑提示。

## M3 大肥鱼老板

`FishBrain.respond(input)` 输入包含当前触发事件、近期事件、船员的渔获、现金、好感与记忆，以及玩家当前发言。输出 JSON 为 `{ say, emotion, action, target, amount }`。表情为平常、高兴、不耐烦、得意、惊讶、哭泣和装睡，台词最多 30 字。模拟层负责执行，浏览器只展示效果。

| 白名单动作 | 玩法和限制 |
| --- | --- |
| `none` | 说话或忽略非法结果，没有资金和世界状态动作 |
| `bonus` | 奖给指定船员，上限为其当班渔获款的 25% |
| `fine` | 指定船员扣款，上限为其当班渔获款的 20%，余额不减至负数 |
| `set_kpi` | 团队目标在基础当班目标的 90%–110% 内调整 |
| `price_change` | 单次最多降 6 或涨 8 个百分点，总鱼价为基础的 85%–115% |
| `spawn_event` | 在码头空位投放有限数量的补给箱 |
| `gift_item` | 给指定船员一次加急鱼饵，普通咬钩等待缩短 2.8 秒 |
| `eat_player` | 短暂吞人并抛回渔场，接续工亡吐槽。欠债吞人和幽灵使用三天指标规则 |

开工、卖鱼、聊天、工亡与绩效面谈共用 8 秒限频。未处理事件最多 6 个，近期事件最多 14 个。先处理开工、面谈和玩家聊天，卖鱼合并等候。好感范围 −100 至 100，每人保留最近 3 条记忆。Mock 拍马屁奖 8%，茶钱 12%，告状裁决扣 18%，基数都是对应船员的当班渔获款。


## M4.5 角色和素材

四个工位使用 Claude、GPT、Kimi 和 Grok。玩家在本地选定角色，联机可以指定空闲角色或自动分配。角色名和动作标签随权威快照传输，客户端播放骨骼动画。挥桨和走跑依输入切换，布娃娃继续由 Rapier 驱动。大肥鱼与玩家角色优先加载，随后加载另外三个工位；表情立绘和音效都从仓库原素材引用。角色行为取向见 [角色设定](dafeiyu-bible.md)。

## M4 房间与同步

| 环节 | 规则 |
| --- | --- |
| 房间 | 随机四位数字码，每房有独立模拟和 FishBrain |
| 工位 | 四个物理工位。加入或退出时切换人类／机器人，保留工位状态和账本 |
| 权威 | Node + ws 每秒运行 60 个模拟步，每 3 步广播一次快照 |
| 客户端输入 | 输入带递增序号，服务端回执已处理的序号。超时的持续移动和蓄力会释放 |
| 预测 | 只预测当前玩家的水平移动和朝向。交互、碰撞、钱和高度由服务端决定 |
| 插值 | 其他船员、鱼、箱子、鱼线、布娃娃和夜袭敌人按约 100 毫秒的快照缓冲插值 |
| 切回前台 | 清除过期的插值缓存和修正偏移，从接到的新权威快照恢复 |
| 重连 | 同一标签页的会话恢复为只读观战，跟随原工位。主动离房时会话失效 |
| 空房 | 最后一个连接离开后保留两分钟 |
| 结算 | 模拟暂停时传输时钟和快照继续，任一在岗玩家可确认下一班 |

房间服务器限制输入大小和排队深度，校验浏览器来源与席位角色。聊天室输入走同一条权威输入路径，老板只在房间服务端运行。
