# 大肥鱼角色设定与素材包（审查者提供）

这份文档和 `assets/dafeiyu/` 由审查者维护。游戏从这一版起改用大肥鱼系列的角色体系：**老板是鲸鱼娘大肥鱼，打工人是其他 AI 娘**。请在下一轮迭代里按「接入任务」替换现有的绿色巨鱼和程序化小人。

## 世界观一句话

大肥鱼是 DeepSeek 的拟人形象，开了一家黑心渔场；Claude、GPT、Grok、Kimi 这些同行 AI 被困在岛上给她打工还债。老板后续会真的接 DeepSeek，所以角色和模型是同一个。

## 角色

### 大肥鱼（老板，id `feiyu`）

- 外形：Q 版鲸鱼娘，深蓝渐变长发、呆毛、鲸鳍耳、鲸尾、蓝白女仆装、蓝蝴蝶结。
- 标志道具和梗：印着鲸鱼的大饭碗（爱吃、饭量大）、头顶不锈钢盆（钢盆防御）、小扇子（过热时扇风）。
- 口头禅和招牌梗：「服务器繁忙，请稍候…」「让我深度思考一下……」「钢盆防御！」「这个我先想 30 秒」。
- 老板人设：嘴碎、爱画饼、偏心、抠门，一边吃饭一边压榨员工；被问急了就「服务器繁忙」装死；深度思考半天给出一个离谱结论。台词不超过 30 字，不辱骂、不涉敏感内容。
- 台词方向举例（可改写扩充，不要照抄成固定模板）：
  - 开工：「今天的 KPI 我深度思考过了：翻倍。」
  - 砍价：「这鱼有点瘦，和我的饭碗不匹配，打八折。」
  - 被告状：「让我深度思考一下……你们俩都扣。」
  - 被贿赂：「鱼我收下了。什么？加薪？服务器繁忙。」
  - 有人落水：「钢盆借你？租金从工资里扣。」
  - 绩效面谈：「你是今天最努力的。所以明天多干点。」

## 接入任务（请排进下一轮，做完打标签 `m4.5`）

1. **老板换成大肥鱼**：海湾中央放 `feiyu.glb`（可以放大并坐在大饭碗或礁石上），去掉原来的绿色巨鱼。气泡旁显示表情立绘，`FISH_EMOTIONS` 映射：`calm→base`、`happy→teary_smile`、`annoyed→angry`、`smug→smug`、`surprised→overheat`。建议把表情枚举扩成也支持 `cry` 和 `sleep`，其中 `sleep` 用在「服务器繁忙」装死的时候。
2. **打工人换成 AI 娘**：四个船员位用 `claude` `gpt` `grok` `kimi` 的模型，玩家开局选一个，其余三个由机器人扮演，机器人的捣乱概率按上表的性格区分。原来的阿铲、桶桶、溜溜改名。
3. **动画对应**：站立 `idle`，移动 `walk` / `run`，挥桨 `chop`，抛竿和收线可用 `box_01` 或 `chop`，日末第一名 `victory_celebration` 或 `cheer`，末位 `afraid`，被甩出去当饵 `dive` 或 `flip`。布娃娃状态继续用物理，倒地期间隐藏骨骼动画或混合到 `fall`，恢复后切回 `idle`。
4. **MockBrain 台词**按上面的大肥鱼人设重写；DeepSeek 适配器的系统提示词也用这份设定。打工人被奖罚时可以用各自的口头禅回嘴。
5. **结算面谈面板**用老板和当事人的表情立绘（第一名 `smug`，末位 `cry`）。
6. **音效**替换或补充现有的程序化音效：拍鱼 `hit1-3`，落水 `splash`，倒地 `thud`，挥桨 `whoosh1-2`，入账 `coin`，结算 `cheer` / `win`。

## 技术约束

- **不要复制素材**：Vite 直接从 `assets/dafeiyu/` 引用（`import url from '...glb?url'` 或把该目录配成静态目录），仓库里只保留这一份。
- **按需加载**：首屏只加载老板和玩家选的角色，其余三个队友和螃蟹在进场后异步加载；加载完成前用现有的程序化小人占位，不能卡住开局。
- **共享动画**：五个角色骨骼和动画同名，写一套 `Actor` 控制器复用；用 `SkeletonUtils.clone` 处理同模型多实例。
- **联机**：快照里只同步角色 id 和动画状态名，不同步骨骼。
- **体积**：整包约 19MB。不要把这些文件再转存进 `docs/screenshots/`，截图仍按每张 300KB 以内。
- 模型来自项目方自己的 dfy-world 项目，贴图为内嵌 JPEG。如果首屏加载超过 5 秒，再考虑做 Draco 或 Meshopt 压缩，先不用动。
