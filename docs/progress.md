## M4.5 · 大肥鱼与四位 AI 工友 · 2026-11-18

### 做了什么

- 根据审查者的角色设定，用鲸鱼娘大肥鱼替换泻湖老板。她坐在饭碗里，气泡随裁决展示对应表情。Claude、GPT、Grok 和 Kimi 代替原有四个船员造型，空位由机器人使用对应角色。
- 本地可选角色，也允许默认用 GPT 立即上工。联机可指定角色或让系统分配，已在岗的角色由服务端拒绝再次占用。角色和动画状态随快照同步，骨骼在浏览器播放。
- 加入走跑、挥桨、钓鱼、活饵、结算得意和害怕动作。被击中的 2 秒仍表现为 Rapier 布娃娃。页面先请求老板与当前玩家模型，再异步加载队友。任何模型加载失败时可继续用程序化造型操作。
- MockBrain 和 DeepSeek 系统提示对齐新设定，新增哭泣和装睡表情。告状识别角色名和玩家昵称，船员会根据奖罚回嘴。面谈显示老板和榜首、末位的立绘。挥桨、落水、击中、交鱼和日榜使用素材包 WAV，等待加载或失败时仍有合成音反馈。

### 实测

- 本机生产构建的无头 Chrome 冷启动 **0.45–0.82 秒可操作**，先请求 `feiyu.glb` 和 `gpt.glb`。另用 Claude 复测，开发构建 0.58 秒可操作、1.80 秒加载完五个模型。拦截老板和玩家模型请求后，角色占位与移动仍可用。
- 浏览器验证从 GPT 改选 Grok、四个角色同时显示、船桨使队友倒地，以及老板在日榜面谈。双客户端分别选 Kimi 与 Claude；两人都请求 Kimi 时，访客收到占用反馈并可以重选。
- 实测 10 个 WAV 解码，首次动作可在加载中直接播放合成音。模拟 HTTP 失败和解码失败后，仍有动作音，静音也生效。老板聊天、限频、结算和外部接口回归通过。四人满房、断线观战与 19.82 Hz 权威快照复测通过。
- 固定种子 `m2-review` 第 3 天，用相同输入按模拟步对比 M4 和 M4.5，两版都是玩家交 10 尾、受扰 6 次，6 尾逃跑、12 次易手，涉及 17 尾不同的鱼。全队 ¥2,106，指标 ¥1,500。
- 原来的 Chrome 长班脚本在相同种子下对输入落步敏感。M4 实测交 7 尾、受扰 6 次、逃 11 尾；M4.5 两次分别为交 8／9 尾、受扰 5／3 次、逃 10／12 尾。M4 的一轮交货量低于旧脚本门槛，M4.5 两次分别在指标比例、干扰次数越过旧门槛，记录原数值供后续复测。

### 已知问题与取舍

- 单个角色文件约 2.7–3.2 MB，弱网可能先看到程序化占位。首班直接可玩，首次选角用右上「选角色」。更换本地角色会重开当前日期。
- 这轮发布沿用 M4 的四分钟白班，螃蟹模型与夜袭稍后随 M5 发布。

## M4 · 四人联机 · 2026-11-18

### 做了什么

- 右上「联机」可创建或加入四位数字房间。真人占用现有工位，机器人补空位。满员时显示提示。不同房间拥有独立的渔场、账本和 FishBrain。
- Node 和 ws 以 60 Hz 运行权威 Rapier 模拟，每 3 步发一份快照。收到回执后只重算自己的水平移动和朝向，其他船员、鱼、箱子、钩和布娃娃在约 100 毫秒的快照窗口内插值。
- 断线立即由机器人接班。原连接自动回来时只读观战，视角跟随原工位，空位可由其他真人加入。切回前台接收并对齐新的权威快照。
- 在职玩家都可以和大肥鱼说话，裁决在服务端应用并广播。可选 DeepSeek 只从 Node 读密钥。Pages 默认加载本地试玩，保留原有三个机器人和 MockBrain。

### 实测

- 用独立无头 Chrome 客户端创建房间并依次加入至 2、3、4 人，检查座位、机器人数和满房提示。收到真实 WebSocket 快照实测 **20.00 Hz**，相邻传输帧差 3 个权威步。
- 用键盘测试位置预测、输入回执和远端收敛。另做 155 毫秒输入延迟测试，自己的画面位置比最新权威位置提前 0.46 米，对方视角按较早的快照插值。
- 冻结访客页面期间，服务端继续推进。另一次复测中停了 75 个权威步，回来后约 200 毫秒内回到约 6 步的插值间隔。通过 TCP 中继主动断开访客后，实测机器人接手、浏览器自动观战、按键无网络输入、第三方补位和显式离房返回本地。
- 实测访客议价后各客户端看到 ×1.06。Node 使用模拟 Chat Completions 响应验证 DeepSeek 裁决进入真实房间快照。房间测试、Brain 测试、M3 本地回归和生产构建通过。

### 已知问题与取舍

- 房间和工位状态保存在 Node 进程内，最后一个连接离开后保留两分钟。断线者恢复为只读观战，同一工位的进度由当前在岗者继承。
- 公共 Pages 提供本地模式。联机使用 `npm run dev` 的房间服务，或在面板填另行托管的 `wss://` 地址。DeepSeek 本轮以模拟响应验通，真实模型可通过服务端 `.env` 配置。
- 大肥鱼设定和参考图在本轮检查时尚未入库，保留现有外形与人设。

### 试玩感受与待审查点

开房后空位已经有人钓鱼，朋友可以随到随进。两端朝同一个秤盘移动时，很容易看出谁在手上搬鱼。请着重试两台设备抢同一条鱼、切后台再继续操作，以及断线时原工位是否好认。

## M3 · 大肥鱼老板 · 2026-11-18

### 做了什么

- 用 `T` 或「找老板」发言。大肥鱼会讨价还价、受用拍马屁、收茶钱并裁决告状。可见效果包括鱼价、奖金、扣款、补给和加急鱼饵。每人独立记录好感和最近三条记忆。
- 开工、卖鱼、聊天、落水工亡和收工面谈共用 8 秒限频。开工会调整当班指标，卖鱼裁决调整后续成交价。结算暂停期间仍可处理面谈回话，场地物理保持冻结。
- 保留原本的大肥鱼几何体和材质，用五种五官动作配合头顶气泡。台词采用现有老板风格，最多 30 字。
- 共享 `FishBrain` 接口和严格 JSON 校验。模拟层处理白名单、金额和目标，奖罚按当班渔获比例。已交付服务端 DeepSeek 适配器及四秒超时回退。Pages 使用 Mock。

### 已知问题与取舍

- 聊天拥挤时要等限频，连续卖鱼会合并。议价后的鱼价从下一笔交货开始生效。
- M3 的吞人是短暂物理演出，幽灵与复活安排在 M5。DeepSeek 联机房间接线安排在 M4。本轮用模拟 HTTP 响应测试，未使用真实 API 密钥。
- 本轮检查时角色设定和参考图尚未入库，沿用现有外形与人设。素材到位后对齐。

### 自己试玩

第一天开工时指标从 ¥1,350 变为 ¥1,404。钓鱼交货后夸老板，能看到奖金和 +7 好感。请喝茶会扣实际鱼款，并记进船员账上。告状时大肥鱼看最近有没有抢鱼或挥桨的记录，也会看双方成绩，没有证据时可能罚告状的人。短场绩效面谈的停表让最后一句话能读完再开下一班。

桌面和触屏无头 Chrome 已复验。实测通过五种触发、八秒限频、赠饵、拍马屁奖金、贿赂扣款、议价、告状裁决和 Enter 续班。服务端测试测到约 4.0 秒超时回退，模拟测试验证越界金额与无效目标的处理。M3 另跑同种子 240 秒 Node 回归，玩家交 10 尾、受扰 6 次，17 尾鱼受到逃跑或易手影响。全队 ¥2,106，原指标 ¥1,500，占 71.2%。

- 有渔获后分别试「收鱼能涨价吗」「老板真英明」「请老板喝茶」和「桶桶偷鱼，我来告状」，观察同一个人的好感、记忆和扣款是否连贯。

## M2 · 机器人与友伤 · 2026-11-18

### 做了什么

- 阿铲、桶桶和溜溜有各自的鱼线、工装和名牌，能自己钓、挥桨、搬运、卖鱼，也会择机截胡。机器人决策以种子和模拟帧为基础。
- 按 E 可从队友手里或半空接走鱼，交货按最后有效触碰者计分。挥桨打中队友会击飞，并让六段布娃娃倒地两秒。
- 先钩住队友，再向海点一次投出活饵。会咬钩的鱼更大，饵员不参与这条鱼的绩效归属。
- 每班 4 分钟，结束弹出绩效榜。首名奖 ¥20，末位下一班戴「待优化」帽，移速降 10%。

### 已知问题与取舍

- M2 的 4 位船员为一位玩家和三位机器人。联机房间安排在 M4，守夜和三天团队指标安排在 M5。
- 结算榜自动显示 8 秒，期间模拟继续。右上「绩效榜」可查看正在进行的一班。

### 自己试玩

和机器人一起交货时，最有趣的位置在秤前。搬鱼的船员会在出手前顿一下，有空从旁边抢，也可以等鱼离手再截。第一次甩队友时，建议开工就对准中间的桶桶，钩上后把准星挪到海里再点一下。

无头 Chrome 跑通了钓鱼交货、钩木箱、队友饵、友伤、手中抢鱼和半空截胡。28 秒短班里，三个机器人各自交货，溜溜拿到 ¥20 年终奖，玩家作为末位戴帽并减速。触屏测试也跑通了钩队友和投饵。

### 请审查者重点看

- 三个机器人是否都能在前几十秒完成交货，以及它们跑过玩家附近时是否太抢戏。
- 先从队友手里抢一单，再试半空截胡。看入账归属和短保护时间是否符合预期。

固定种子会先遇到气鼓鱼。刚拖上岸时能接空中一桨，再补一桨就有倍率。最容易空挥的是鱼从脚边弹过的时候，盯住落点比追它当下的位置更容易再拍中。

无头 Chrome 实机验证了气鼓鱼以 ×1.55 入账 ¥53、木箱上岸和撞箱后两秒恢复。390 × 844 的触屏测试也卖出了一条鱼。
